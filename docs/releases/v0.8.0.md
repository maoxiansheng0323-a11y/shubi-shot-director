# Shubi Shot Director v0.8.0

Shubi Shot Director v0.8.0 replaces the browser's low-detail shaped actor
surfaces with a refined white mannequin while preserving the complete v0.7
actor-control and SceneSpec contracts.

## Refined white mannequin

- One audited built-in CC0 derivative of Blender Studio Human Base Meshes
  v1.4.1 provides a more anatomical head, facial planes, torso, pelvis, arms,
  hands with fingers, legs, and feet with toes.
- Sixteen normalized mesh sections follow the existing fifteen canonical joint
  frames. Stature, pose, limb presence, actor transforms, reusable Blueprint
  variants, and ground contact continue to work without schema changes.
- The renderer replaces only supported body primitives. Face direction markers,
  shoulder/elbow/hip/knee indicators, and Blueprint box/sphere/cylinder modules
  remain procedural and editable.
- Loading and runtime-node validation are closed to the fixed built-in URL.
  Loading, missing, duplicate, extra, or invalid nodes select the complete
  procedural fallback without blocking scene editing.

## Asset integrity

- The committed GLB is 603,548 bytes with SHA-256
  `1bd1bf8650a0e2b0d35e8544bca4d21a99069bcf2bd4b26974cf1b5ac1857b94`.
- It contains 35,904 triangles, sixteen mesh nodes, one material, and no skins,
  armatures, animations, cameras, lights, images, or textures.
- The source ZIP, official URLs, CC0 license, source SHA-256, stable node list,
  conversion method, and reproduction command are recorded in
  [`docs/assets/refined-white-mannequin-v1.md`](../assets/refined-white-mannequin-v1.md).
- The source archive and portable Blender executable remain untracked research
  inputs; only the optimized derivative, manifest, converter, and provenance
  are part of the repository.

## Compatibility

- Application version: 0.8.0.
- SceneSpec, ScenePatch, and IntentReport schema version: 6.
- Capability contract: 2; bridge protocol: 1; workspace routing: 1.
- Existing `actor.height`, `actor.pose-joints`, limb-presence, and Blueprint
  instance override capability IDs remain available.
- Existing v1-v5 migrations, v6 persistence, atomic Patch behavior, locks,
  Actor Blueprint snapshots, fifteen joints, stature, limb presence, contact,
  composition, diagnostics, and browser PNG export remain unchanged.
- The analytical projection remains authoritative for bounds, contact,
  composition, software diagnostics, and compatibility. The GLB is not scene
  state and no scene stores an asset path or renderer choice.

## Scope

This remains graybox camera previs. v0.8.0 does not add arbitrary GLB import,
custom character assets, skinning, inverse kinematics, animation authoring,
finger or toe articulation, facial performance, clothing, hair, textures,
physics, or production asset management.
