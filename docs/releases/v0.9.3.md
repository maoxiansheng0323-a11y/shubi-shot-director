# Shubi Shot Director v0.9.3

Shubi Shot Director v0.9.3 is a direct-manipulation maintenance release. It
keeps the v0.9.2 editor navigation model while making camera, actor-part, and
editor-focus gestures deterministic across the built-in graybox renderers.

## Corrected direct manipulation

- The compact Shot Preview is rendered above the editor canvas so the final
  shot remains visible and interactive in the combined studio workspace.
- A focused camera proxy now rotates in place on left-drag. An unfocused camera
  proxy retains direct movement, and the existing gizmos remain available for
  precise transforms.
- Pressing and dragging an actor's head or supported limb focuses the actor and
  green part, then adjusts the mapped canonical joint in the same gesture.
- Loaded refined mannequin sections use the same raycast-mesh pointer ownership
  as the procedural fallback. Joint drags continue through document pointer
  events after leaving the visible mesh and commit only after the drag threshold.
- Editor auto-framing no longer resets an intentionally positioned view on
  repeated focus changes. It rearms only after the user zooms outward beyond
  the guarded distance.
- Head, face, and neck geometry target the canonical `neck` joint. Horizontal
  motion turns, vertical motion nods, roll is excluded, and the result is
  clamped to a usable cervical range.

## Authority and compatibility

Each completed camera, entity, or actor-part gesture still authors at most one
validated ScenePatch, one scene revision, and one undo step. Editor camera,
selection, focus, live drafts, and compact-preview layout remain transient UI
state and do not enter SceneSpec or change the active shot camera implicitly.

- Application version: 0.9.3.
- SceneSpec, ScenePatch, and IntentReport schema version: 6.
- Capability contract: 2; bridge protocol: 1; workspace routing: 1.
- Existing `actor.pose-joints`, actor height, limb-presence, Blueprint,
  persistence, composition, and PNG export contracts remain available.
- No persistent schema, migration, generated-schema, or dependency change was
  made.
- This remains graybox camera previs. v0.9.3 does not add inverse kinematics,
  animation authoring, physics, arbitrary mesh editing, final artwork
  generation, or production asset management.

## Verification status

The repeatable gates and dated evidence are recorded in
[`docs/verification.md`](../verification.md#v093-direct-manipulation-maintenance-gates).
The final `pnpm verify` gate passed 97 test files with 1,963 tests, the separate
workspace e2e test (1/1), TypeScript, ESLint, the production Vite build, and a
293-file public audit with zero findings. The generic-output audit also scanned
293 files with zero findings.

Browser checks at 1280 x 720 and 800 x 900 confirmed nonblank Studio and Shot
Preview rendering, correct preview-over-editor layering, no horizontal
overflow at the compact breakpoint, and no console warnings or errors. In an
isolated generic scene, editor double-click focus did not change revision 1;
one direct head drag selected the green part, changed only the canonical
`neck` joint, and committed exactly revision 2. Screenshot crops had nonzero
RGB variance and entropy above 6.36 at both viewports. Final visual taste
remains a human approval boundary.
