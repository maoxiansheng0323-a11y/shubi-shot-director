# Shubi Shot Director v0.4.0

Shubi Shot Director v0.4.0 expands the public graybox previs workflow from a
single editable shot into connected environments, explicit protection rules,
editable generic anatomy, and direct final-camera operation.

## Highlights

### Connected-region environments

- Author arbitrary same-floor regions, boundaries, openings, and sight or
  passage connections in one structured scene.
- Inspect Overview, Local preview, and the authoritative Shot Preview without
  changing persistent scene state.
- Hide the first blocking wall when the final camera moves outside a room, so
  browser preview and PNG export stay readable.

### Lock provenance

- Distinguish unfinished `none`, workflow checkpoint `workflow`, and explicit
  user protection `user` locks.
- Apply ordinary corrections atomically with `preserveLock: true`, preserving
  workflow locks without asking for extra authorization.
- Keep user-protected edits as an explicit stop-and-confirm boundary.

### Editable limb presence

- Store canonical `present` or `absent` state for twelve generic humanoid limb
  segments.
- Enforce parent-child limb consistency across authoring, patches, rendering,
  contact, composition, persistence, undo, and export.
- Keep prostheses, replacement parts, injuries, and production character
  systems outside the graybox contract.

### Direct final-camera controls

- Open Shot Preview and adjust the final camera immediately, without a hidden
  activation mode.
- Left-drag to pan, right-drag to orbit around the composition target, and use
  the wheel to change focal length in millimeters.
- Move with the six-button camera pad, arrow keys, or `PageUp` / `PageDown`.
- Explain a user-protected camera inside Shot Preview and offer an explicit
  in-preview unlock action before direct controls become available.
- Suppress the initial right-button press before it can open the host context
  menu, including while the camera remains user protected.
- Preserve one gesture as one revision and one undo step while respecting lock
  provenance.

## Contracts And Upgrade Notes

- SceneSpec, ScenePatch, and IntentReport use schema version 4.
- The capability contract remains version 2 and continues to require host
  semantic authority, structured-only input, forbidden credentials, and
  loopback-only networking.
- Existing supported scene versions migrate explicitly; unsupported semantics
  fail instead of silently degrading.
- The package remains private to npm. Install from source with pnpm and run
  `node scripts/director.mjs doctor` before starting the local bridge.
