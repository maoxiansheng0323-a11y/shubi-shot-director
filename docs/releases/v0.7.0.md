# Shubi Shot Director v0.7.0

Shubi Shot Director v0.7.0 publishes the adjustable actor puppet contract for generic legacy and reusable Blueprint actors while preserving SceneSpec authority, Host-only semantics, structured runtime input, and graybox-only scope.

## Adjustable actor puppets

- Both actor branches support resolved stature from 1.0 through 2.4 meters through `actor.height.set`.
- Fifteen canonical joints cover pelvis, spine, neck, both arm chains, and both leg chains. Hand and foot joints provide wrist and ankle articulation.
- `actor.pose.joints.set` updates one joint or a small set without replacing the complete action. Stored joint quaternions remain normalized.
- Every canonical v6 stored pose and create submission now carries exactly those fifteen joints. Empty, sparse, or non-canonical joint maps are rejected instead of silently rendering a named action as neutral.
- `actor.limb-presence.set` works for legacy and Blueprint actors. Blueprint instance overrides layer above the immutable base snapshot and selected variant.
- Height, limb, joint, action, and variant edits share deterministic contact correction, atomic revision, undo, redo, save, and reload behavior.
- Browser and software projections share tapered human-readable profiles for the head, neck, torso, pelvis, thighs, and lower legs while remaining editable graybox geometry.

## Public contracts

- Application version: 0.7.0.
- SceneSpec, ScenePatch, and IntentReport schema version: 6.
- Capability contract: 2; bridge protocol: 1; workspace routing: 1.
- New feature IDs: `actor.height`, `actor.pose-joints`, and `actor.blueprint-instance-limb-overrides`.
- The capability manifest publishes exact stature limits, fifteen joint IDs, incremental operation IDs, and stable height/joint recovery codes.
- Actor Blueprint document schema remains version 1. Embedded snapshots, canonical SHA-256, modules, proportions, and skeleton data remain immutable.
- v1-v5 compatibility for a complete SceneSpec, an actor `entity.add`, and a complete-action `actor.pose.set` Patch uses the known historical pose-joint alias mappings. Canonical keys win when both forms exist, missing canonical joints receive identity quaternions, and every other unknown pose key is discarded.
- Complete v5 SceneSpec migration rebases only contact-owned Y for enabled Blueprint ground contact under `none`, `workflow`, and `user` locks while preserving the stored revision, lock mode, pose preset, X/Z, rotation, and scale. A v5 Patch that newly adds a `workflow`- or `user`-locked Blueprint actor plus enabled ground contact receives the same contact-only rebase in its single revision; native v6 additions still follow ordinary lock enforcement.
- CLI v1-v4 Patch input normalizes to one canonical v6 Patch and is forwarded directly; only v5 is rebuilt as a sanitized v5 compatibility payload and reparsed for canonical equivalence. The executable command and complete public boundary are maintained in the [v0.7.0 Patch source-integrity gate](../verification.md#v070-patch-source-integrity-gate).

## Skill authoring

- Create submissions distinguish legacy `body.heightM` from Blueprint `blueprintInstance.heightScale`, default Blueprint instance overrides, and materialize complete fifteen-joint actions.
- Follow-up submissions use exact snapshot `sceneId` and `baseRevision`, minimal actor operations, `preserveLock: true` for workflow corrections, and stop on user locks.
- Inspector joint semantics use local right-handed XYZ: X bend, Y twist, and Z side-bend. Host Codex resolves natural-language direction from actor-local and visible shot context.
- Visual QA checks Overview, affected Local previews, and Shot Preview for stature, missing limbs, wrist/ankle pose, contact, persistence, and Blueprint SHA stability.

## Scope

This release remains graybox camera previs. It does not add final image generation, arbitrary mesh import, inverse kinematics, animation, physics, skinning, or project-specific actors.
