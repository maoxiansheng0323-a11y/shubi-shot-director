# Shubi Shot Director v0.6.0

Shubi Shot Director v0.6.0 adds reusable, external Actor Blueprints for deterministic graybox characters while preserving SceneSpec authority, structured-only Host semantics, and legacy actor compatibility.

## Highlights

### Reusable path-free snapshots

- Host Codex validates an explicitly supplied external JSON document through `blueprint validate --file`.
- SceneSpec embeds a canonical schema-versioned snapshot with a content SHA-256, so saved scenes reopen without the source file.
- Equal content reuses one snapshot. Duplicate content under another ID and the same ID with different content are rejected instead of silently overwritten.
- Multiple actors in one scene can independently reference one snapshot.

### Modular graybox structure

- Blueprint modules combine box, sphere, and cylinder primitives.
- Modules attach to supported shoulder, elbow, wrist, hip, and knee frames and follow pose rotation and movement.
- The scope remains graybox-only: no custom mesh import, skinning, IK, animation, or physics.

### Delta-only variants

- Variants override only limb presence and module visibility.
- Each variant resolves from the complete base, never from the previous selected variant.
- The Inspector shows a read-only blueprint summary and selects only variants already embedded in the snapshot.

### One actor projection

- Browser rendering, visible bounds, contact enforcement, composition inspection, anchors, and software diagnostics consume one resolved actor projection.
- Legacy actors use the same projection path and preserve their v0.5 resolved primitives.

### Privacy and persistence

- External file paths remain at the Host import boundary and never enter SceneSpec, ScenePatch, IntentReport, history, diagnostics, logs, screenshots, or exports.
- Blueprint snapshots survive save/load, restart, undo, redo, and source-file removal.
- v0.6 adds no snapshot removal operation and performs no automatic garbage collection.

## Contracts and upgrade notes

- Application and Skill version: 0.6.0.
- SceneSpec, ScenePatch, and IntentReport use schema version 5.
- Actor Blueprint document schema version: 1.
- Capability contract remains version 2; bridge protocol remains 1, and workspaces still require `workspaceRoutingVersion: 1` plus `bridge.thread-workspaces`.
- Existing generic legacy actor documents migrate without manual edits.
- The package remains private to npm.

## Scope

This release stops at reusable graybox previs. It does not add final-art generation, arbitrary mesh import, a general character editor, complex IK, animation, physics, skinning, or project-specific character data.

## Verification

The release gate covers strict schema bounds, canonical hashing, conflict priority, Host path isolation, multi-instance deduplication, delta variants, projection parity, all geometry consumers, Inspector selection, save/load and history, real browser Shot Preview export, and the repository public/generic audit.
