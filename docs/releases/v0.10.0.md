# Shubi Shot Director v0.10.0

Shubi Shot Director v0.10.0 is the Graybox Craftsman update. The project's
recent direction places less emphasis on automatically acting as the user's
cinematographer and more emphasis on becoming a dependable builder of editable
graybox scenes. This release packages three already reviewed improvements from
the production baseline without adding another feature or persistent contract.

## Passive/resting static blocking

- Low-profile and supine actors now choose bounded, same-surface resting
  targets for an available relaxed arm before considering a more active raised
  posture.
- The remaining arm can rest beside the body or on the actor's support surface
  with a more natural passive silhouette while preserving deterministic
  shoulder, elbow, wrist, contact, and penetration checks.
- This is a focused static-blocking improvement. It does not introduce general
  inverse kinematics, animation, physics, or runtime semantic inference.

## Refined mannequin attachment calibration

- Independently centered GLB section AABBs are no longer treated as rig pivots.
  Closed per-section calibration maps the measured proximal attachment axis
  back onto the authoritative analytical projection.
- Shoulders, hips, and other major visible connections therefore follow the
  canonical actor projection more faithfully instead of inheriting visual
  offsets from independent section normalization.
- The calibration is renderer mapping only. Scene joints, Blueprint mounts,
  limb presence, bounds, contact, composition, persistence, and diagnostics
  continue to use the analytical projection as their single authority.

## Reference-guided scene reconstruction

- When a user explicitly supplies one or a few reference images, Host Codex may
  use them as transient evidence for an editable graybox reconstruction.
- The Host separates certain, inferred, and unresolved observations, then
  extracts spatial topology, scale anchors, furniture relationships, occupied
  volumes, functional clusters, circulation, and lived-in density.
- Reconstruction uses the existing SceneSpec v6 spatial graph and editable
  primitive vocabulary. Reference images, image paths, source wording, aliases,
  and private metadata never enter runtime input or persistent scene data.
- Camera selection remains manual and user-directed. The workflow does not add
  runtime image understanding, automatic shot selection, prefab authoring, or a
  new persistent reconstruction format.

## Authority and compatibility

- Application version: 0.10.0.
- SceneSpec, ScenePatch, and IntentReport schema version: 6.
- Capability contract: 2; bridge protocol: 1; workspace routing: 1.
- The runtime remains model-free, structured-only, credential-forbidden, and
  loopback-only. Host Codex remains the sole semantic authority.
- Existing v6 scenes and structured submissions remain compatible. No schema,
  migration, dependency, or capability-contract version is bumped for this
  release.

## Scope boundary

The Draft semantic shot and automatic-camera experiment in PR #7 is not
included in v0.10.0. This release does not mark that work ready, merge it, close
it, create a v1.0.0 contract, or publish a v1.0.0 tag.

Shubi Shot Director remains bounded graybox still-shot previs. It does not add
final image generation, production asset management, animation authoring,
physics gameplay, arbitrary mesh editing, or a general-purpose 3D engine.
