# Shubi Shot Director v0.9.0

Shubi Shot Director v0.9.0 turns the browser editor into a directly manageable studio
while keeping shot cameras independent from editor navigation.

## Direct studio workflow

- The main viewport is a full-size studio with a UI-only editor camera. Overview
  and Local remain editor filters, while a compact active-camera preview
  continuously shows the active persistent shot camera.
- A single click selects an actor, prop, or camera. Double-clicking frames the
  editor camera at a deterministic editing scale and enters red entity focus.
  Right-click and `Escape` clear transient selection and focus state.
- Focused actors, props, and camera proxies can be moved directly with the
  mouse. Arrow keys move the focused entity relative to the editor view, and
  `PageUp`/`PageDown` move on world Y. Workflow locks remain preserved; user
  locks stay inspectable but mutation-blocked.
- After an actor is focused, clicking a supported body segment enters green
  part focus. Dragging that segment from the current editor viewpoint authors
  one canonical local joint, so orbiting the editor camera changes the meaning
  of the same screen gesture without introducing IK or multi-joint inference.

## Independent shot cameras

- Double-clicking a scene camera also activates it for the compact preview and
  frames its proxy in the studio. Selecting a camera in the compact selector
  switches the active shot angle without changing studio selection or focus.
- Expanded Shot Preview remains the authoritative camera refinement and export
  surface. Right-drag uses free rotation by default; an explicit actor or prop
  target can be selected when target orbit is wanted. Left-drag translation,
  lens changes, undo/redo, lock preservation, conflict cancellation, and
  browser-rendered PNG export retain their existing revisioned contracts.

## Compatibility and scope

- Application version: 0.9.0.
- SceneSpec, ScenePatch, and IntentReport schema version: 6.
- Capability contract: 2; bridge protocol: 1; workspace routing: 1.
- Existing `actor.pose-joints`, actor height, limb-presence, and Blueprint
  capability IDs remain available.
- No persistent scene schema changes were made. Editor camera position,
  selection, focus, selected joint, preview expansion, and live drafts remain
  UI state.
- This remains graybox camera previs. v0.9.0 does not add inverse kinematics,
  animation authoring, physics, arbitrary mesh editing, batch camera export,
  final artwork generation, or production asset management.
